# Snigdha Das — Personal Developer Portfolio 🌐

A clean, modern, and high-performance developer portfolio built with semantic **HTML5**, modern **Vanilla CSS3**, and **JavaScript (ES6+)**. Designed with a **Luminous Modernist** aesthetic featuring glassmorphism, responsive bento grids, dynamic dark/light theme switching, and interactive project filters.

## ✨ Features

- 🌓 **Dual Theme Engine (Dark & Light Mode)**: Toggle between a cosmic dark theme with ambient glow accents and a crisp, high-legibility light theme. Saves your preference in `localStorage`.
- 🪟 **Glassmorphic Floating Navigation**: Semi-transparent blurred navbar with active section scroll spy (`IntersectionObserver`) and mobile drawer menu.
- ⚡ **Interactive Project Filtering**: Filter featured projects dynamically across *All*, *Full-Stack*, *Frontend & React*, and *IoT & Hardware*.
- 📋 **One-Click Email Copy**: Clickable contact widget to copy email address instantly with toast notifications.
- 📱 **Fully Responsive Layout**: Built mobile-first with CSS Grid and Flexbox, looking sharp across smartphones, tablets, and large displays.
- 📄 **Integrated Resume / CV**: Direct link to downloadable and viewable PDF resume (`SNIGDHA DAS .pdf`).
- 🚀 **Zero External Framework Dependencies**: Pure Vanilla HTML/CSS/JS for ultra-fast load times and zero build steps required.

## 🚀 Getting Started & Local Development

No package manager or build step is required! You can run this website directly in your browser:

### 1. Clone the Repository
```bash
git clone https://github.com/Snigdha-2005/portfolios.git
cd portfolios
```

### 2. View in Browser
- Simply double-click **`index.html`** to open it in your default web browser.
- Or use the VS Code **Live Server** extension for real-time live reload.
- Or run a quick local Python server:
```bash
# Python 3
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Deploying to GitHub Pages

To make your portfolio live on the web for free using GitHub Pages:

1. Push this repository to your GitHub account (`https://github.com/Snigdha-2005/<repo-name>`).
2. Go to your repository on GitHub and click **Settings**.
3. In the left sidebar, click **Pages** (under *Code and automation*).
4. Under **Build and deployment > Branch**, select `main` (or `master`) and folder `/ (root)`.
5. Click **Save**.
6. Within a minute, your portfolio will be live at:
   ```text
   https://<your-username>.github.io/<repo-name>/
   ```
